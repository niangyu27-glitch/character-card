所以以后如果你要改的是编辑器本身的功能和界面，基本都可以只改
app/src/main/assets/preview.html
例如：

增加新的角色卡字段
增加新的输入框
增加/删除分类
修改页面布局
修改颜色、字体、按钮
修改生成 YAML 的格式
增加自动保存内容
增加新的预览功能
增加更多动态条目
增加导入/导出功能（纯网页逻辑范围内）

涉及 Android 原生能力时，就不一定只改 preview.html。

例如：

需要改 MainActivity.kt
调用系统文件选择器
读取手机文件
保存文件到手机指定位置
系统分享
通知
权限
Android 原生数据库
桌面小组件
系统级设置
